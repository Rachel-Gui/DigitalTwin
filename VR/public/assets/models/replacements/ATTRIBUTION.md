# School replacement assets

The WebXR school scene uses optimized, locally hosted derivatives of the following assets.

- Island Tree 02, Pine Sapling Small, Shrub 04, Fern 02, Grass Medium 02, Modular Street Seating, and Modular Chainlink Fence by Poly Haven contributors. License: CC0 1.0. Source: https://polyhaven.com/models
- Car Concept from Khronos Group glTF Sample Assets. The source model was created by Unity Fan and released as CC0; the Khronos asset was optimized for web delivery by Eric Chadwick and contributors. Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CarConcept

The checked-in GLB files were reduced to 1K textures, geometry-simplified where appropriate, WebP texture-compressed, and Meshopt-compressed for this WebXR project. The original Enscape proxy meshes are not included in these replacements.
